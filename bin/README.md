# 📚 文档问答 RAG 助手

### 项目简介
基于纯 Python 手写实现的 RAG（检索增强生成）问答系统。使用 TF-IDF 进行文本向量化，DeepSeek API 作为生成模型。

### 📊 实验结果与调优记录
测试集规模：30题（涵盖事实查询、数值统计、元数据抓取、防幻觉测试）

| 实验编号 | 切块大小 (Chunk Size) | 检索数量 (Top_K) | 准确率 (Accuracy) | 关键优化点/结果 |
| :--- | :--- | :--- | :--- | :--- |
| Exp-1 | 300 | 3 | 60% | 表格被切碎，数值查询失败 |
| Exp-2 | 350 | 3 | 70% | 关键优化点：完整的表格被保留，数值题正确率提升 |
| Exp-3 | 350 | 5 | 待测 | 增加上下文数量，预计能覆盖跨段落的问题 |
